Google gets you from zero to your first API response in minutes. This guide walks you through creating an account, generating credentials, and verifying that everything works with a single test request — no prior setup required.

## Prerequisites

Before you begin, make sure you have the following:

- A **Google account** — sign up for free at [app.google.com](https://app.google.com) if you don't have one yet.
- A **modern browser** (Chrome, Firefox, Safari, or Edge) to access the dashboard, or an **HTTP client** such as `curl`, Postman, or Insomnia to make API calls.

---

## Steps

<Steps>

  ### Sign Up or Log In

  Open [app.google.com](https://app.google.com) in your browser. If you already have an account, click **Log In** and enter your credentials. If you're new, click **Sign Up**, enter your email address and a strong password, then verify your email using the confirmation link sent to your inbox.

  Once authenticated, you land on your **Dashboard** — the central hub for all your projects and settings.

  ### Generate an API Key

  API keys authenticate every request you make to the Google API. To create one:

  1. Click **Settings** in the left sidebar.
  2. Select **API Keys** from the Settings menu.
  3. Click **New Key** in the top-right corner.
  4. Give your key a descriptive name (for example, `my-first-key`) and click **Create**.
  5. Copy the key immediately — it is only shown once.

  <Note>
    Keep your API key secret. Never commit it to source control, expose it in client-side code, or share it publicly. If a key is compromised, revoke it immediately from **Settings → API Keys** and generate a new one.
  </Note>

  ### Make Your First API Call

  With your key in hand, verify that everything is working by calling the ping endpoint. This lightweight endpoint confirms your credentials are valid and returns the current API version.

  <CodeGroup>

  ```bash cURL
  curl -X GET https://api.google.com/api/v1/ping \
    -H "Authorization: Bearer <YOUR_API_KEY>"
  ```

  ```python Python
  import requests

  response = requests.get(
      "https://api.google.com/api/v1/ping",
      headers={"Authorization": "Bearer <YOUR_API_KEY>"}
  )
  print(response.json())
  ```

  ```javascript Node.js
  const response = await fetch("https://api.google.com/api/v1/ping", {
    method: "GET",
    headers: {
      Authorization: "Bearer <YOUR_API_KEY>",
    },
  });

  const data = await response.json();
  console.log(data);
  ```

  </CodeGroup>

  A successful response looks like this:

  ```json Response
  {
    "status": "ok",
    "version": "1.0"
  }
  ```

  If you receive a `401 Unauthorized` error, double-check that you copied the full API key and that the `Authorization` header is formatted exactly as shown above.
