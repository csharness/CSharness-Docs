The Google SDK provides a type-safe, idiomatic client for every supported language, so you can interact with the API without writing raw HTTP requests. Choose the package that matches your stack, install it in one command, and you'll have a working client in minutes.

## Available packages

Google publishes official SDK packages for three languages:

| Language | Package | Registry |
|---|---|---|
| JavaScript / TypeScript | `@google/sdk` | npm |
| Python | `google-sdk` | PyPI |
| Go | `google-sdk-go` | pkg.go.dev |

All packages follow the same semantic-versioning policy and are updated in lockstep with the REST API. TypeScript types are bundled directly inside `@google/sdk` — no separate `@types/` package is required.

## Install the package

Run the command for your language and package manager. Use the same terminal session where your project already lives so the dependency is added to the correct manifest.

<CodeGroup>

```bash npm
npm install @google/sdk
```

```bash yarn
yarn add @google/sdk
```

```bash pnpm
pnpm add @google/sdk
```

```bash pip
pip install google-sdk
```

```bash go get
go get github.com/google/google-sdk-go
```

</CodeGroup>

<Tip>
  If you use a `requirements.txt` or `pyproject.toml` file, pin the SDK to a minor version range (e.g. `google-sdk>=1.4,<2`) to receive patch updates without unexpected breaking changes.
</Tip>

## Initialize the client

After installation, import the SDK and create a client instance. Pass your API key at construction time — the client reuses that key for every subsequent request.

<Tabs>
  <Tab title="JavaScript / TypeScript">
    ```typescript title="src/googleClient.ts"
    import { GoogleClient } from "@google/sdk";

    const client = new GoogleClient({
      apiKey: process.env.GOOGLE_API_KEY,
    });

    export default client;
    ```
  </Tab>
  <Tab title="Python">
    ```python title="google_client.py"
    from google_sdk import GoogleClient
    import os

    client = GoogleClient(
        api_key=os.environ["GOOGLE_API_KEY"],
    )
    ```
  </Tab>
  <Tab title="Go">
    ```go title="client.go"
    package main

    import (
        "os"
        google "github.com/google/google-sdk-go"
    )

    func main() {
        client := google.NewClient(
            google.WithAPIKey(os.Getenv("GOOGLE_API_KEY")),
        )
        _ = client
    }
    ```
  </Tab>
</Tabs>

<Warning>
  Never hard-code your API key in source files. Store it in an environment variable or a secrets manager and read it at runtime, as shown above.
</Warning>

## Set a custom base URL

By default the SDK targets the production API at `https://api.google.com/v1`. You can override this to point at a staging or self-hosted environment by passing a `baseUrl` option during initialization.

<Tabs>
  <Tab title="JavaScript / TypeScript">
    ```typescript title="src/googleClient.ts"
    import { GoogleClient } from "@google/sdk";

    const client = new GoogleClient({
      apiKey: process.env.GOOGLE_API_KEY,
      baseUrl: process.env.GOOGLE_BASE_URL ?? "https://api.google.com/v1",
    });

    export default client;
    ```
  </Tab>
  <Tab title="Python">
    ```python title="google_client.py"
    from google_sdk import GoogleClient
    import os

    client = GoogleClient(
        api_key=os.environ["GOOGLE_API_KEY"],
        base_url=os.getenv("GOOGLE_BASE_URL", "https://api.google.com/v1"),
    )
    ```
  </Tab>
  <Tab title="Go">
    ```go title="client.go"
    package main

    import (
        "os"
        google "github.com/google/google-sdk-go"
    )

    func newClient() *google.Client {
        baseURL := os.Getenv("GOOGLE_BASE_URL")
        if baseURL == "" {
            baseURL = "https://api.google.com/v1"
        }

        return google.NewClient(
            google.WithAPIKey(os.Getenv("GOOGLE_API_KEY")),
            google.WithBaseURL(baseURL),
        )
    }
    ```
  </Tab>
</Tabs>

<Info>
  The custom base URL option is useful when working with [environment-specific configurations](/configuration/environment). See the [examples page](/code/sdk/examples) for a complete environment-aware client pattern.
</Info>

## TypeScript types

The `@google/sdk` package ships with full TypeScript declarations. No additional installation step is required — your editor will surface autocomplete and inline documentation as soon as you import from the package.

```typescript title="src/types-example.ts"
import { GoogleClient, Resource, ListResourcesResponse } from "@google/sdk";

const client = new GoogleClient({ apiKey: process.env.GOOGLE_API_KEY });

async function getResource(id: string): Promise<Resource> {
  return client.resources.get(id);
}
```
