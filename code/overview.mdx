Google exposes a versioned REST API that gives you programmatic access to every resource in the platform — workspaces, projects, knowledge bases, and more. Whether you are building an internal tool, automating content workflows, or embedding Google into an existing product, this section is your technical reference. Start here to understand what is available, then drill into the specific area you need.

## What's in This Section

The Code Docs section is organized into three main areas:

- **API Reference** — complete endpoint documentation for every REST resource, including request parameters, response shapes, and example payloads.
- **SDK Libraries** — official client libraries for JavaScript/TypeScript, Python, and Go that wrap the REST API with idiomatic interfaces.
- **Advanced Topics** — rate limits, security hardening, webhook integration, and versioning strategy.

## Base URL

All API requests are made over HTTPS to the following base URL. Append the resource path directly after this prefix.

```bash
https://api.google.example/v1
```

The version segment (`/v1`) is part of every request URL. When new major versions are released, the base URL changes to `/v2`, `/v3`, and so on — older versions remain available during the deprecation window. See [Versioning](/code/advanced/versioning) for the full policy.

## Authentication

Every request to the API must include a Bearer token in the `Authorization` header. You generate tokens from your account's API settings page. Tokens are scoped (read-only vs. read-write) and can be restricted to specific workspaces.

```bash
Authorization: Bearer <your_api_token>
```

Full details — including token rotation, OAuth 2.0 flows, and workspace-scoped credentials — are covered in the [Authentication reference](/code/api/authentication).

## Available SDK Languages

Google publishes and maintains official SDK libraries in the following languages:

| Language | Package | Minimum Version |
|---|---|---|
| JavaScript / TypeScript | `@google-example/sdk` | Node.js 18+ |
| Python | `google-example-sdk` | Python 3.9+ |
| Go | `github.com/google-example/sdk-go` | Go 1.21+ |

All three libraries are generated from the same OpenAPI specification and are kept in sync with the latest API version. Installation instructions and quickstart examples are in the [SDK section](/code/sdk/installation).

## Versioning Approach

Google uses **URL versioning**. The version is the first path segment after the host:

- `/v1` — current stable version
- `/v2` — next major version (in preview, where applicable)

Minor, backwards-compatible changes — new optional fields, new endpoints, expanded enum values — are added to the current version without a version bump. Breaking changes always ship in a new version. You will receive advance notice before any version is sunset.
