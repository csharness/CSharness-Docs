## Where to Begin

If this is your first time here, follow the path below to get up and running:

<Steps>
  <Step title="Create your account">
    Sign up and complete your profile. See [Account Setup](/get-started/account-setup) for the full walkthrough.
  </Step>
  <Step title="Get your API key">
    Generate an API key from your dashboard and learn how to authenticate requests. See [Authentication](/configuration/authentication).
  </Step>
  <Step title="Make your first call">
    Follow the [Quick Start](/quickstart) guide to send your first API request and verify everything is working.
  </Step>
  <Step title="Explore integrations">
    Connect the tools you already use. See [Integrations](/guides/integrations) for supported platforms and setup instructions.
  </Step>
</Steps>
